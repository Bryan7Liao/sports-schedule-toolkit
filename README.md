# 中華職棒賽程整理工具包（2027 球季）

把中華職棒大聯盟（CPBL）官網公告的例行賽賽程，整理成 **Google Sheet（月份表、聯盟日曆、六隊日曆）** 與 **六張球隊賽程海報** 的完整流程紀錄。
文件以 2027 球季為例，換年度時照著「換年度檢查清單」重做即可。

## 2. 整體流程

```
官網公告（圖片） ──► 放大逐格轉錄 ──► Python 資料檔（360 場）
                                        │
                                        ├─► 自動驗證（場數／主客場平衡）
                                        │
                     ┌──────────────────┼──────────────────┐
                     ▼                  ▼                  ▼
              月份表（3–10月）      聯盟日曆（一頁）     六隊日曆（各一頁）
                     │
                     └──► 依同一套配色 ──► 六張球隊賽程海報
```

所有表格與海報都由**同一份資料檔** `scripts/schedule_2027.py` 產生，修正一處即可全部同步。

## 3. 資料來源與擷取

- **來源**：中華職棒官網新聞公告〈2027 中華職棒例行賽賽程〉，2026/11/24 發布。
  網址：`https://www.cpbl.com.tw/news/cont?sid=0Q328606205264427553`
- **格式**：賽程以兩張 PNG 圖片公布（上半季、下半季），頁面本身沒有文字。
- **讀圖格式**：每格寫成 `客隊( )主隊`，例如 `象( )龍` 代表**中信兄弟作客、味全龍主場**。
- **隊名簡稱對照**：

| 圖上簡稱 | 球隊全名 | 表格簡稱 |
|---|---|---|
| 龍 | 味全龍 | 味全 |
| 象 | 中信兄弟 | 兄弟 |
| 獅 | 統一7-ELEVEn獅 | 統一 |
| 悍將 | 富邦悍將 | 富邦 |
| 桃猿 | 樂天桃猿 | 樂天 |
| 雄鷹 | 台鋼雄鷹 | 台鋼 |

### 擷取方式

1. 用瀏覽器打開圖片網址，把圖片放大約 1.4 倍，分段截圖逐格閱讀。
   （官網擋爬蟲，無法直接下載圖片檔，所以改用瀏覽器顯示。）
2. 轉錄成 `scripts/schedule_2027.py` 裡的 `raw` 字串，一行一天：
   ```
   4/2 龍@象 雄鷹@悍將 獅@桃猿
   4/3 =4/2
   ```
   - `客@主`：一場比賽
   - `=4/2`：與 4/2 對戰組合相同（三連戰常見）
3. 同時記下**非比賽日**：優先補賽日、補賽預備日、加賽保留日、明星賽、季後賽與總冠軍賽預定日。

### 2027 年的已知瑕疵

- 原圖第 10 週週五的日期格寫成「7」，依前後日期判斷應為 **5/28**，表格已照 5/28 處理。
- 公告只有對戰組合，**沒有球場與開賽時間**，所以表格沒有這兩欄。

## 4. 資料驗證

轉錄完一定要先跑驗證，確認沒有漏看或看錯：

```bash
cd scripts
python3 schedule_2027.py
```

2027 年應得到的結果：

| 檢查項目 | 預期值 |
|---|---|
| 全季總場數 | 360 |
| 上、下半季各 | 180 場 |
| 每隊每半季主場 / 客場 | 各 30 場 |
| 任兩隊每半季交手 | 12 場 |
| 每隊全季 | 120 場（主 60、客 60） |

任何一項不符就代表轉錄有錯，回頭對照原圖。
另外可抽查星期：例如 3/27 應為週六，跟原圖一致。

## 5. Google Sheet 結構

分頁順序：`2027日曆` → 六隊日曆 → `3月`～`10月`。

### 5.1 月份表（`3月`～`10月`）

| 欄 | 內容 | 說明 |
|---|---|---|
| A | 日期 | 日期格式 `yyyy/mm/dd` |
| B | 星期 | `B2` 一格公式自動帶出整欄：`=ARRAYFORMULA(IF(A2:A="","",MID("日一二三四五六",WEEKDAY(A2:A),1)))` |
| C | 客隊 | 全名 |
| D | 主隊 | 全名，整列底色依此欄決定 |
| E | 季別 | 上半季 / 下半季 |
| F | 備註 | 補賽日、明星賽、下半季開賽等 |
| H1:H7 | 主場底色圖例 | 六隊色票 |

- 非比賽日也列進表中（客隊、主隊留空），顯示灰色斜體。
- 第 1 列凍結，表頭底色 `#5B6470`、白字。

### 5.2 聯盟日曆（`2027日曆`）

- 3 月到 10 月，**每列並排兩個月**，週一在最左，跟官方賽程圖一樣。
- 每週 4 列：1 列日期 + 最多 3 列比賽。
- 比賽格式：`客隊 vs 主隊`（簡稱），例如 `兄弟 vs 味全`。
- 非比賽日以 `※` 開頭，例如 `※補賽預備日`。
- 有備註的比賽日把備註寫在日期旁，例如 `4 優先補賽日`、`2 下半季開賽`。
- 欄寬：日期欄 92px，兩個月之間的間隔欄 24px；隱藏格線。

### 5.3 六隊日曆（`味全龍`、`中信兄弟`…）

- 版面同聯盟日曆，但每週只有 2 列：日期 + 該隊當天比賽。
- 比賽寫法：
  - 主場：`主 vs 對手`，例如 `主 vs 兄弟`
  - 客場：`客 @ 主隊`，例如 `客 @ 樂天`
- 第 1 列標題以球隊簡稱開頭（例如 `味全｜味全龍 2027 例行賽賽程…`），條件式格式靠這個辨認「自己是哪一隊」。
- 第 2 列右側自動統計：
  - `K2`：`=COUNTIF(B4:P80,"主 *")`（主場數）
  - `M2`：`=COUNTIF(B4:P80,"客 *")`（客場數）
  - `O2`：`=K2+M2`（合計）
- 做法：先完整做好一隊的分頁，再用「複製工作表」複製出另外五隊，最後只替換內容。

## 7. 條件式格式規則

顏色全部用**條件式格式**而不是手動塗色，改資料時顏色會自動跟著變。

| 分頁 | 套用範圍 | 自訂公式 | 效果 |
|---|---|---|---|
| 月份表 | `A2:F` | `=$D2="味全龍"`（六隊各一條） | 整列套該主隊淡色 |
| 月份表 | `A2:F` | `=AND($A2<>"",$D2="")` | 非比賽日：灰底斜體 |
| 聯盟日曆 | `B3:P` | `=REGEXMATCH(TO_TEXT(B3),"vs 味全$")`（六隊各一條） | 比賽格套主隊淡色 |
| 聯盟日曆 | `B3:P` | `=REGEXMATCH(TO_TEXT(B3),"^[0-9]+($| )")` | 日期列：淺灰底、粗體 |
| 聯盟日曆 | `B3:P` | `=LEFT(TO_TEXT(B3),1)="※"` | 非比賽日：灰色斜體 |
| 六隊日曆 | `B4:P` | `=OR(REGEXMATCH(TO_TEXT(B4),"@ 味全$"),AND(LEFT(TO_TEXT(B4),2)="主 ",LEFT($B$1,2)="味全"))` | 客場格套主隊色；主場格套自己隊色 |

> 日期列的規則用 `^[0-9]+($| )`，而不是 `^[0-9]`，是為了避免「3月」這種月份標題也被染成日期列的灰色。

## 9. 腳本說明

所有腳本放在 `scripts/`，需要 Python 3.9 以上，只用標準函式庫。

| 檔案 | 用途 | 產出 |
|---|---|---|
| `schedule_2027.py` | **唯一資料來源**：轉錄的賽程與驗證 | 直接執行會印出驗證結果 |
| `build_month_sheets.py` | 產生 `3月`～`10月` 月份表要寫入的資料 | `m3.json`～`m10.json` |
| `build_league_calendar.py` | 產生 `2027日曆` 的格子內容與格式設定 | `calgrid.json`、`calreq.json` |
| `build_team_calendars.py` | 產生六隊日曆的格子內容與格式設定 | `t_<隊>.json`、`teamreq.json` |
| `build_posters.py` | 用範本產生六張海報 | `out/project/*.dc.html` |
| `templates/poster_template.dc.html` | 海報範本（`__TEAM__`、`__PB__` 等是替換用的佔位字） | — |

產出的 `*.json` 是 Google Sheets API 的請求內容（`values` 陣列或 `batchUpdate` 請求），可直接拿去呼叫 API。

## 10. 換年度檢查清單

1. [ ] 到官網找新年度的〈例行賽賽程〉公告，確認賽程格式是否仍為「客隊( )主隊」。
2. [ ] 複製 `schedule_2027.py` 改成新年度檔名，重新轉錄 `raw`，並更新各腳本的 `import`。
3. [ ] 更新年份：腳本裡的 `2027`、日曆用的 `calendar.Calendar(0).monthdatescalendar(年份, 月)`。
4. [ ] 更新非比賽日清單（優先補賽日、補賽預備日、明星賽、季後賽等）。
5. [ ] 跑 `python3 schedule_<年份>.py`，確認總場數、主客場、交手數都平衡。
6. [ ] 確認球隊名單與名稱沒有變動（新球隊、改名、換主場）；有變動就更新簡稱對照與配色表。
7. [ ] 依序產生月份表 → 聯盟日曆 → 六隊日曆，各分頁讀回來抽查。
8. [ ] 產生海報並逐張目視檢查有沒有文字被切掉。
9. [ ] 在每份成果標注資料來源與公告日期。

## 11. 踩過的坑

| 問題 | 原因 | 解法 |
|---|---|---|
| 官網文字抓不到 | 賽程是圖片 | 用瀏覽器放大圖片分段閱讀 |
| `curl` 下載圖片被擋 | 官網阻擋 | 改在瀏覽器裡顯示圖片 |
| 新增的條件式格式順序跟預期相反 | `addConditionalFormatRule` 沒給 `index` 時，新規則會插到**最前面** | 要更新特定規則前，先讀回規則清單確認 index |
| 換配色後舊顏色沒消失 | 舊規則還在，只是被新規則蓋住 | 刪掉或覆寫多出來的舊規則 |
| 寫入 `"3/27"` 被轉成日期 | Sheets 寫入值會像手動輸入一樣自動判斷型別 | 日期刻意寫成 `2027/03/27` 讓它成為真日期；想保留文字就加 `'` |
| 一次送出的格式設定太大 | 六個分頁各送一份重複的設定 | 只做好一頁，其餘用 `duplicateSheet` 複製，再改內容 |
| 月份標題被染成日期列顏色 | 規則 `^[0-9]` 也會比對到「3月」 | 改成 `^[0-9]+($| )` |
| 官方圖上的錯字 | 原圖日期格寫錯 | 依前後日期推斷，並在文件中註明 |
