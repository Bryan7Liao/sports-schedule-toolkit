# 運動賽程整理通用手冊

這份手冊說明如何把**任何聯盟或賽事**的官方賽程，整理成一致的資料檔、Google Sheet 與賽程圖。
流程是從中華職棒 2027 的實作歸納出來的（完整範例見 [`examples/cpbl-2027`](../examples/cpbl-2027/README.md)），再擴充到 MLB、NFL、日本職棒、國際賽等不同賽制。

各聯盟的球隊數、場數與官方資料來源，整理在 [LEAGUES.md](LEAGUES.md)。

## 1. 先判斷賽制類型

不同賽制的版面與驗證方式差很多，動手前先分類：

| 類型 | 特徵 | 代表賽事 | 主要呈現方式 |
|---|---|---|---|
| **A. 聯盟日賽制** | 幾乎天天比賽、系列賽（2～4 連戰）、主客場固定 | 中華職棒、日本職棒、韓國職棒、MLB、NBA | 月曆 |
| **B. 週賽制** | 每週一場、有輪休週（bye week）、以「第幾週」排程 | NFL、多數足球聯賽 | 週次表 |
| **C. 國際錦標賽** | 分組循環＋淘汰賽、中立場地、淘汰賽對手要等前一輪結果 | WBC、世界盃足球、奧運、亞運、12 強 | 分組表＋賽程樹 |

一個賽事可能混合兩種，例如日本職棒有「交流戰」，足球聯賽中間有盃賽。原則是：**主體用哪一種，就用那種版面**，其他的當備註處理。

## 2. 標準流程

```
1. 取得官方賽程 ──► 2. 轉成通用 CSV ──► 3. 驗證
                                           │
        ┌──────────────────────────────────┼──────────────────────┐
        ▼                                  ▼                      ▼
4. Google Sheet（明細表）       5. Google Sheet（日曆／週次表）      6. 賽程圖（每隊一張）
```

- **單一資料來源**：所有表格與圖片都從同一份 `games.csv` 產生，修正一處就全部同步。
- **先驗證再做表**：驗證沒過就不要往下做，回頭對原始資料。
- **顏色用條件式格式**，不手動塗色，資料改了顏色會跟著變。

## 3. 通用資料格式

每個賽事一個資料夾，放三個 CSV 和一個 `profile.json`。範本在 [`templates/`](../templates)。

### 3.1 `games.csv`：一列一場比賽

| 欄位 | 必填 | 說明 | 範例 |
|---|---|---|---|
| `game_id` | ✓ | 唯一編號，官方有場次編號就用官方的 | `2027-001` |
| `date` | ✓ | 比賽所在地的日期，`YYYY-MM-DD` | `2027-03-27` |
| `local_time` | | 比賽所在地的開賽時間，未定留空 | `18:35` |
| `timezone` | | IANA 時區名稱 | `Asia/Taipei`、`America/New_York` |
| `week` | B 類必填 | 第幾週 | `1` |
| `stage` | | 階段：上半季、下半季、例行賽、分組賽、八強… | `上半季` |
| `group` | C 類分組賽填 | 組別 | `C` |
| `home` | ✓ | 主隊 `team_id`；中立場地填「名義主隊」 | `WEI` |
| `away` | ✓ | 客隊 `team_id` | `CTB` |
| `neutral` | | 中立場地填 `true` | `false` |
| `venue` | | 球場 | `天母棒球場` |
| `note` | | 雙重賽 `DH`、海外賽、延期等 | `DH-1` |
| `source` | | 資料來源與日期 | `CPBL 官網公告 2026-11-24` |

**淘汰賽對手未定**時，用代號當 `team_id`，例如 `A1`（A 組第一）、`W57`（第 57 場勝隊），並在 `teams.csv` 補上這些代號，等對手確定再替換。

### 3.2 `teams.csv`：一列一隊

| 欄位 | 必填 | 說明 |
|---|---|---|
| `team_id` | ✓ | 自訂代碼，建議 2～4 個英文字母 |
| `short_name` | ✓ | 表格與圖上用的簡稱（2～4 字） |
| `full_name` | ✓ | 正式全名 |
| `group` | | 分區、分組（例如 `AL East`、`Pool C`） |
| `primary` / `primary_text` | | 實色與實色上的文字色，給圖片與主場格用 |
| `pastel` / `pastel_text` | | 淡色與淡色上的文字色，給試算表用 |

### 3.3 `events.csv`：非比賽的聯盟日程

明星賽、補賽日、季後賽預定日、休兵日等。欄位：`date`、`label`、`scope`（`league`／`postseason`／隊伍代碼）。

### 3.4 `profile.json`：驗證規則

| 欄位 | 說明 |
|---|---|
| `format` | `league`／`weekly`／`tournament` |
| `season_start`、`season_end` | 例行賽起訖，用來抓日期打錯的場次 |
| `total_games` | 全部場數 |
| `games_per_team`、`home_games_per_team` | 每隊場數、主場數 |
| `pair_games` | 任兩隊交手場數（每對都一樣時才填） |
| `by_stage` | 依階段分別設定上述數字，例如上、下半季 |
| `max_games_per_team_per_day` | 一般為 1；有雙重賽的聯盟設 2 |
| `max_games_per_team_per_week` | 週賽制設 1 |
| `group_stage_name` | 錦標賽分組賽的 `stage` 名稱，用來檢查同組才對戰 |
| `min_contrast` | 顏色對比下限，預設 4.5 |

數字填 `0` 或不填，就代表不檢查那一項。

## 4. 取得資料

依官方釋出的格式，難度由低到高：

| 來源格式 | 做法 | 例子 |
|---|---|---|
| **CSV／ICS 下載** | 直接下載後轉欄位 | MLB 各隊官網有可下載的 CSV 賽程 |
| **公開 API／JSON** | 用程式抓取，存成原始檔再轉 | MLB 的 `statsapi.mlb.com`（非正式文件，由社群整理） |
| **網頁表格** | 複製表格或用程式解析 HTML | 日本職棒、韓國職棒官網的賽程頁 |
| **PDF** | 用 PDF 文字擷取，再整理欄位 | NFL 依分區列出的賽程 PDF |
| **圖片** | 放大逐格轉錄，最容易出錯，務必驗證 | 中華職棒 2027 賽程公告 |

共通原則：

- **保留原始檔**：下載的 CSV、API 回應、截圖都存起來，日後對照用。
- **記下抓取日期**：賽程會改（延賽、時間異動、翻轉轉播場次），`source` 欄寫清楚是哪一天的版本。
- **先抓全聯盟，不要一隊一隊抓**：用各隊賽程拼起來，容易重複或漏場。MLB 這類只提供各隊檔案的聯盟例外，拼完後要用 `game_id` 或「日期＋主隊」去除重複。
- **讀圖時先確認格式慣例**：例如中華職棒圖上是「客隊( )主隊」，美式寫法常見「客隊 @ 主隊」，國際賽可能「A vs B」不分主客。

## 5. 驗證

用通用驗證工具：

```bash
python3 tools/validate_schedule.py --data <資料夾> --profile <資料夾>/profile.json
```

會檢查：

| 檢查 | 抓得到的錯誤 |
|---|---|
| 欄位、日期格式、未知隊伍、自己打自己 | 打錯字、漏欄位 |
| 日期在季賽範圍內 | 年份或月份打錯 |
| 每隊每天（每週）場數上限 | 同一隊同一天排兩場（非雙重賽） |
| 總場數、每隊場數、主場數 | 漏場、多抄一場、主客對調 |
| 任兩隊交手數（含分階段） | 對手看錯 |
| 錦標賽同組對戰 | 分組抄錯 |
| 顏色對比 | 底色太淺或文字看不清（警告） |

有任何「✗ 失敗」時結束碼為 1，可以放進自動化流程。

**驗證以外還要抽查**：

- 開幕戰、明星賽、最後一天對照官方新聞。
- 星期幾跟原始資料一致（日期轉錯時常會整週偏移）。
- 每隊首戰與最終戰。

不是每個聯盟的主客場都完全平衡。例如 MLB 每隊主、客場通常各 81 場，但遇到海外賽或場地因素可能有例外。這時在 `profile.json` 不要填 `home_games_per_team`，改用人工確認。

## 6. Google Sheet 版面

### 6.1 通用分頁

| 分頁 | 適用 | 內容 |
|---|---|---|
| 明細表（依月或依週分頁） | 全部 | 日期、星期、時間、客隊、主隊、階段、球場、備註；整列依主隊上色 |
| 聯盟總覽 | A、B | A 類用月曆，B 類用週次表 |
| 各隊分頁 | A、B | 每隊一頁，只看自己的比賽 |
| 分組與賽程樹 | C | 分組積分表格＋淘汰賽對戰圖 |

**隊伍很多時（MLB 30 隊、NFL 32 隊）不要每隊做一個分頁**，改做一個「選隊伍」的分頁：在 `B1` 用下拉選單選隊伍，下面用 `FILTER` 公式帶出該隊賽程，例如：

```
=FILTER(明細!A2:H, (明細!E2:E=$B$1)+(明細!F2:F=$B$1))
```

### 6.2 A 類：月曆

- 每列並排兩個月，週一或週日在最左，跟官方慣例一致（中華職棒、日本職棒用週一；美國聯盟常用週日）。
- 聯盟總覽：每週 1 列日期＋每天最多 N 列比賽（N＝當天最多場數，中華職棒 3、MLB 15）。MLB 這種一天十幾場的聯盟，總覽改用明細表，月曆只做各隊。
- 各隊月曆：每週 1 列日期＋1 列比賽，寫法 `主 vs 對手`、`客 @ 主隊`。雙重賽寫成 `主 vs 對手 ×2`。
- 右上角用公式統計主場、客場、合計場數。

### 6.3 B 類：週次表

- 列＝球隊，欄＝第 1～N 週，格子寫對手：主場 `vs 對手`、客場 `@ 對手`、輪休寫 `BYE`。
- 另做一張「依日期」明細表，因為同一週的比賽可能分散在週四到週一。
- 最後一週日期未定時（例如 NFL 第 18 週），日期與時間欄留空並在備註寫「待定」。

### 6.4 C 類：錦標賽

- 分組表：每組一個區塊，列出對戰、日期、當地時間、觀賞地時間。
- 賽程樹：淘汰賽對戰位置先用代號（`A1 vs B2`），確定後再換成隊名。
- 中立場地不分主客顏色，改用「組別色」或「賽事主色」。

### 6.5 條件式格式公式

| 用途 | 自訂公式範例 |
|---|---|
| 明細表整列依主隊上色 | `=$F2="主隊全名"`（每隊一條） |
| 日曆格依主隊上色 | `=REGEXMATCH(TO_TEXT(B3),"vs 隊名$")` |
| 各隊分頁：客場依主隊、主場依自己 | `=OR(REGEXMATCH(TO_TEXT(B4),"@ 隊名$"),AND(LEFT(TO_TEXT(B4),2)="主 ",LEFT($B$1,2)="隊名"))` |
| 日期列 | `=REGEXMATCH(TO_TEXT(B3),"^[0-9]+($| )")` |
| 非比賽日 | `=LEFT(TO_TEXT(B3),1)="※"` |
| 星期欄（整欄一個公式） | `=ARRAYFORMULA(IF(A2:A="","",MID("日一二三四五六",WEEKDAY(A2:A),1)))` |

注意：用 API 新增規則（`addConditionalFormatRule`）時若不指定 `index`，**新規則會插在最前面**。之後要改規則前，先讀回清單確認順序。

## 7. 配色系統

每隊兩組顏色，存在 `teams.csv`：

| 用途 | 欄位 | 原則 |
|---|---|---|
| 試算表底色、圖片的客場格 | `pastel` / `pastel_text` | 同色系淡色，長時間看不刺眼 |
| 圖片頂部色帶、圖片的主場格 | `primary` / `primary_text` | 球隊代表色實色 |

規則：

1. **對比至少 4.5:1**：黃、橘、淺綠這類亮色配深色字，不要配白字。驗證工具會自動檢查。
2. **相近色要拉開深淺**：例如紅與深紅、兩支藍色系球隊。只靠色相分辨，色弱的人看不出來。
3. **隊伍超過 8 隊時不要一隊一色**：30 隊的顏色一定會撞。改成：
   - 各隊圖片只分「主場（自己隊色）／客場（中性灰或對手所屬分區色）」；
   - 聯盟總覽依**分區**上色（例如 MLB 6 個分區、NFL 8 個分區）。
4. **國際賽**：依組別或國家代表色，中立場地不分主客。
5. 顏色是自訂的視覺識別，不是官方色票；若要用官方色碼，先查各球團的品牌規範。

## 8. 賽程圖設計

### 8.1 共通規格

| 項目 | 建議 |
|---|---|
| 尺寸 | 直式 1200×2400（手機、社群限動）或 1080×1350（社群貼文） |
| 結構 | 頂部色帶（賽事名、隊名、首戰、場數統計）→ 圖例 → 主體 → 頁尾（資料來源、以官方公告為準） |
| 字體 | 中文 Noto Sans TC；數字與英文 Barlow Condensed 或同類窄體 |
| 文字大小 | 對戰文字至少 13px（1200 寬），手機上才看得清 |
| 主場格 | 隊色實色＋`vs 對手` |
| 客場格 | 主場球隊淡色＋`@ 主隊`（隊伍多時用中性灰） |
| 非比賽日 | 淺灰；補賽日、明星賽、季後賽小字標註 |

### 8.2 依賽制調整主體

| 類型 | 主體版面 | 注意 |
|---|---|---|
| A. 中華職棒、韓國職棒（6～10 隊，120～144 場） | 2 欄 × 4 列月曆 | 一張放得下整季 |
| A. 日本職棒（143 場）、MLB（162 場） | 月份較多或場次密集時，分上下半季兩張，或每月一張 | 雙重賽格子標 `DH`；海外賽另加標記 |
| B. NFL（17 場，18 週） | 18 列週次清單：週次、日期、對手、主客、開賽時間 | 輪休週獨立一列；第 18 週日期待定 |
| C. 國際賽 | 上半部分組賽程、下半部賽程樹 | 時間同時列「當地」與「觀賞地（例如台灣）」時間 |

### 8.3 產生方式

範例 [`examples/cpbl-2027/scripts/build_posters.py`](../examples/cpbl-2027/scripts/build_posters.py) 用一個 HTML 範本加上資料，自動產生每隊一張圖。換賽事時：

1. 複製範本，改頂部文字與月份範圍。
2. 依 8.2 調整主體版面（月曆／週次清單／分組＋賽程樹）。
3. 每張圖產生後逐張目視檢查，確認沒有文字被切掉。

## 9. 時區與日期

- **`date` 一律用比賽所在地的日期**。美國西岸晚場在台灣已是隔天，若用台灣日期，月曆會整個錯位。
- 要給台灣觀眾看時，另外加「台灣時間」欄位或在圖上標註，不要覆蓋原始資料。
- 跨國賽事（WBC、世界盃）分組在不同國家進行，每場都要有自己的 `timezone`。
- 夏令時間：美國、歐洲在季中會切換，換算時用時區名稱（`America/New_York`），不要寫死「-5」。
- 日期寫進 Google Sheet 時用 `YYYY/MM/DD`，避免被當成月/日或日/月誤判。

## 10. 新賽事上手清單

1. [ ] 判斷賽制類型（第 1 節），查 [LEAGUES.md](LEAGUES.md) 有沒有現成資料。
2. [ ] 找到官方賽程來源，記下網址與公告日期，存原始檔。
3. [ ] 建立資料夾 `examples/<賽事>-<年度>/`，複製 `templates/` 的三個 CSV 與對應的 `profile_*.json`。
4. [ ] 填 `teams.csv`：代碼、簡稱、全名、分組、兩組顏色。
5. [ ] 把賽程轉成 `games.csv`；非比賽日寫進 `events.csv`。
6. [ ] 填 `profile.json` 的場數規則，跑驗證工具直到全部通過。
7. [ ] 抽查開幕戰、明星賽、最後一天、星期幾。
8. [ ] 做 Google Sheet：明細表 → 總覽 → 各隊（或選隊分頁）。
9. [ ] 做賽程圖，逐張檢查。
10. [ ] 在範例資料夾寫一份 `README.md`，記下這個賽事特有的狀況（資料格式、官方錯字、未定場次）。

## 11. 版權與資料使用

- **賽程事實**（日期、對戰）可以整理引用，但要標注來源，並寫「實際賽程以官方公告為準」。
- **隊徽、吉祥物、字標是商標**，不要自己畫或放進圖片；需要時使用球團正式授權的檔案。
- **非官方 API**（例如 MLB Stats API）沒有正式授權條款，適合個人或內部整理；要公開發布或商業使用前，先確認聯盟的使用規範。
- 官方新聞稿、圖片本身有著作權，不要整份轉貼，只擷取需要的賽程資料。
